# 「今日复习」真机验收与真人试用记录

## 1. 首页到首题计时

- 在同一台实体 iPhone、同一 iOS 版本下比较。旧版用 TestFlight `1.0 (3)`，从「背词」页点右上角带铅笔的「测验自测」。新版用已准备好的「今日复习」候选，从「背词」页点「开始复习」。记录两个构建标识及新版源码快照标识。
- 两版都使用测试专用数据。预置相同的 5 个英语核心词为已到期，保持相同的到期顺序、语种、难度、自动朗读设置和系统音量。旧版选择「专攻到期」与每轮 5 词。新版保持无未完成续练，由相同的 5 个到期词组成一轮。每次只看到首题，提交答案留到单独的功能验收。若出现旧轮，下一次计时前在隔离环境重新载入测试快照。使用独立测试设备或各自已隔离的测试安装，保留设备上现有的学习数据。
- 做 5 个配对，每个配对各测一次旧版和新版。奇数对先旧后新，偶数对先新后旧。每次从已冷启动并打开「背词」页开始，保持操作员、显示设置和屏录帧率一致。VoiceOver 另测，此表只记录普通触控。记录卡住、误触和展示空白的实际结果；出现操作错误时保留备注并补跑这一对。
- 用同一设备的本地屏录逐帧读时。T0 是背景停止切换、背词首页及对应入口首次显示且入口可用的帧。T1 是第一题完整题干及可选答案同时显示、答案按钮可操作的首帧。记录从 T0 到 T1 的毫秒数和点击次数。若本地屏录缺少可信帧时间，统一用秒表记录到 0.1 秒，并在表中标明方法。启动 App 至首页的耗时和首次答题用时分开记录。

## 2. 真机功能验收

只在隔离的候选安装中使用合成学习数据。每个续练场景从新的测试词组开始。需要验证写入时，在测试前后导出本地 JSON 备份，比对测试词的 `reviewEvents` 与 `progressRecords`。从系统 App 切换器上滑强退后，用原图标重新打开。

| 检查 | 操作和通过条件 | 记录（通过 / 失败 / 待测） |
| --- | --- | --- |
| VoiceOver | 在系统辅助功能中开启 VoiceOver，从首页开始左右轻扫，应听到「开始复习」或「继续复习」及其按钮角色。双击进入后，依次读到题干、选项和按钮角色，焦点可移至可操作控件。双击作答后应能听到已选项或反馈，再找到「下一题」或「稍后继续」。在听音题继续核对播放入口和「不便听音，换文字题」，换题后题号不跳且新题可读。 | |
| 无声 | 关闭 VoiceOver 后开静音模式，把媒体音量调为 0，并确认无外接音频。关闭闪卡自动朗读。进入听音题，无需播放即可点「不便听音，换文字题」。题号保持不变，切换本身不增加复习事件。提交文字首答后仅新增一笔。 | |
| 首答前续练 | 记下题号、题干、选项顺序。强退重开，首页显示「继续复习」，回到相同题目与选项，事件数维持原值。 | |
| 反馈阶段续练 | 提交一次错答，看到反馈后强退。重开后恢复该题的已选答案与反馈，能前往下一题，只有第一次提交写入复习事件和排期。 | |
| 补练阶段续练 | 完成首答，进入错词补练后强退。重开应恢复相同补练位置。完成后补练分数上升，复习事件数与该词排期维持原值。 | |

失败记录包含构建、场景、预期、实际结果与可复现步骤。测试备份和录屏留在本机，报告只使用匿名设备代号和合成词组。

## 3. 真人 A/B 记录

真机计时比较的是 App 新旧入口。下列 A/B 比较使用离线原型，两者分别记账。A 用原短练题式，B 把两道看词选义换为配对，词义配对仅在试用原型中。真机验收使用的合成词组与真人 D+1 探测词组分开。 [主持人说明](主持人说明.md) · [统计口径](../VOCABULARY_PILOT.md#统计口径和推进门槛)

1. D0 按原方案发放匿名编号，冻结次日到期词，平衡 AB/BA 顺序与词组映射。在同一离线界面完成两轮，每轮 6 词。通过 `rounds.csv` 记录首题实际展示及结算实际展示。中途退出保留为已开轮，未开轮人数单独记录。
2. D+1 只在冻结到期时间后揭示探测题，保持遮蔽条件，不显示对错。将首次有效提交写入 `probes.csv`，受干扰、未答与迟到沿用既有口径。保留所有已分派的 `assignment.csv`，含未开轮或缺席者。

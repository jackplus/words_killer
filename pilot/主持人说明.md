# 词汇短练试用主持人说明

每位试用者完成两天。D0 做两轮各 6 词的离线短练，D+1 做一轮 12 词的盲测。目标 12 位自愿试用者，AB、BA 两种顺序和两种词组分配合计四种组合，各安排 3 人。主持人照读本页话术，使用同一台电脑、同一浏览器和相同的时间安排。 [对照方案与判定规则](../VOCABULARY_PILOT.md)

## 开跑前

1. 在有 Python 3.9 或以上版本的 Mac 上准备题包，使用系统已安装的离线英语语音。提前用合成题包在断网状态试听并确认音量、耳机和浏览器下载可用。用桌面 Chrome 打开本地网页，无需启动服务器。以下终端命令均在仓库根目录执行。 [离线试用网页](index.html)
2. 整批试用先确定同一本英语词书、同一个随机种子和 `Asia/Taipei` 时区。日历中的 D0 是短练当天，D+1 是下一自然日。主持人按预先安排发 `P01` 到 `P12` 的编号，同一个编号贯穿两天。
3. D0 展示题目之前，用 Words Killer 在「设置」导出当天的本地备份。运行以下命令，替换日期、路径和时刻。`--probe-by` 填第二天约定测评开始的当地时刻，脚本只选不晚于该时刻到期的词。省略 `--book` 时使用内置核心词库，整批统一改用另一册时把该册 JSON 路径传给 `--book`。

   ```sh
   python3 pilot/prepare.py \
     --slot 1 \
     --cohort-seed 'pilot-01' \
     --day YYYY-MM-DD \
     --probe-by 19:00 \
     --backup '/本机私有目录/当天备份.json' \
     --output '/本机私有目录/试用数据/P01'
   ```

4. 确认输出中有 `participant.json` 和 12 行分派记录的 `assignment.csv`。主持人私下检查两套词组难度相近、没有明显近义、近形或同音干扰。若脚本提示词量不足或无法组对，推迟这一位的入组。题目一旦展示，保留原编号、题包和到期名单。
5. 在 Chrome 点击「导入参与者题包」，选择 `participant.json`，核对匿名编号和日期。备份可能含学习笔记等非试用信息，留在原持有人本机。试用目录只存匿名题包、进度文件和 CSV，主持页、题包内容和分派表由主持人看管。

## D0 短练

### 话术

> 这次试用有两轮短练，每轮六个词。请按照屏幕上的指示作答，听音题可点按钮播放。系统会在相应题目或题块提交后给出反馈，错题会在本轮最后补练一次。两轮中间休息两分钟。我们只用编号记录试用数据。你可以随时停止。

### 操作

1. 在 D0 卡片上点「开始第 1 轮」，让试用者接手。首题展示才算开始。主持人统一说明操作，保持两轮可用时间一致，避免额外提示正确答案，按界面顺序完成两轮。
2. 第一轮看到结算后点「返回主持页」，再点「下载进度备份」。从结算开始等满两分钟后，界面开放第二轮。完成首答和应做补练、实际看到结算才算完成。每轮结束保存进度，D0 收尾点击「下载 rounds.csv」。
3. 每位参与者在一个标签页作答。如有中断，点击「暂停并返回主持页」和「下载进度备份」。继续时先导入原 `participant.json`，再点击「导入进度」载入该参与者最新备份。听音失败时先暂停排查音量或耳机，无法恢复时结束本轮，保持两组的题型条件一致。确认停止时用「结束本轮」，已开轮记为 `abandoned`，未展示首题的轮次用「登记未开始」记为 `not_started`。`rounds.csv` 对每个已分派的 `round_id` 保留一行，两轮都没开始也保留两行。未完成轮次留在完成率分母，未开始轮次另报。
4. 提醒试用者到 D+1 测评前尽量避免另练这些词。主持人不提示词表、正确答案或分组。记录中断、设备或音频故障等异常时仅用编号。

## D+1 次日测评

### 话术

> 这轮按中文释义选择英文词，请按第一次想到的答案作答。测评过程中不会告诉你对错。如果你在见到测评题前用其他方式复习过相关词，请先告诉我。需要停止时可以直接说。

### 操作

1. 到 D+1 当天导入原 `participant.json` 和最新进度。确认系统时间正确。所有词都已到达冻结时刻后，点「开始次日测评」。任何词尚未到期时留在主持页。
2. 测评开始前或展示该题前，由主持人在主持页勾选已在别处重练、已提前看过测评题的词。开始后才发现时，先点击「暂停并返回主持页」标记，再继续测评。它们留在已分派词数中，作答文件记为 `prior_exposure`。如果试用者说不清受干扰的是哪一词，先确认范围再展示该题。
3. 在混排题目中按顺序记录首次有效提交。A、B 题目采用同一题型，测评界面隐藏分组和答案。中断时下载进度备份和已有 `probes.csv`。D+1 自然日结束后停止测评。迟到未测用匿名代号单独记录，既有提交按原时间保留。
4. 点击「下载 probes.csv」。试用者未到场时，该编号仍保留在分派文件中，复制空 `probes.csv` 模板。若其 D0 未开轮，按对应的两个轮次 ID 填 `not_started`，开始、结算时间留空。 [分派模板](templates/assignment.csv) · [轮次模板](templates/rounds.csv) · [测评模板](templates/probes.csv)

## 汇总与判定

每位参与者的目录内保留原始 `participant.json`、冻结的 `assignment.csv` 和最新导出的 `rounds.csv`、`probes.csv`。浏览器重复下载时可能在文件名后加编号，请核对匿名编号并将最新版保存为规定的文件名。不要把同一人的多个版本附加在一起。把以下命令中的路径换成实际路径，汇总目录使用新路径。

```sh
python3 pilot/merge.py '/本机私有目录/试用数据' '/本机私有目录/试用汇总'
python3 scripts/vocabulary-pilot.py '/本机私有目录/试用汇总' --through YYYY-MM-DD
```

`--through` 填最后一个已完整结束的台北自然日。统计结果保留正确率、覆盖率、完成率的分子分母，以及 AB、BA 的分别结果。`advance` 表示达到预设下一轮开发门槛，`hold` 表示资料量足够但效果或完成率未达标，`insufficient` 表示资料量、观察记录或覆盖不足。 [完整口径](../VOCABULARY_PILOT.md#统计口径和推进门槛)

## 先用合成数据走一遍

```sh
dry_run_dir=$(mktemp -d)
python3 pilot/rehearsal.py --day 2026-11-24 --output "$dry_run_dir/rehearsal"
open -a 'Google Chrome' pilot/index.html
```

演练命令会生成 12 人的平衡分派、可在网页打开的合成题包、汇总 CSV 和统计判定。导入演练输出的 `participant.json`，操作首答、补练、结算、进度恢复和 D+1。演练界面允许虚拟推进中间休息和次日时钟。演练输出留在单独目录，真人试用目录仅收实际观察记录。

若使用试用分发包，先解压整个目录，再打开 `pilot/index.html`。要先试做一轮，可直接导入随包的 `demo/participant.json`。
